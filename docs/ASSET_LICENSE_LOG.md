# Asset License Log

更新日期：2026-05-27

本文件记录《保护区之外》所有外部、AI 生成或手工修改素材的来源和授权。没有记录的素材不得进入公开参赛包。

## 使用规则

- `assets/source/` 保存源文件、工程文件、AI 原图或参考处理结果。
- `assets/sprites/` 保存 Godot 可直接使用的导出图。
- 使用 CC-BY、付费授权或其他需署名素材时，必须记录署名文本。
- Minecraft 和《植物大战僵尸》素材只能作为私人占位，不得出现在公开参赛包。
- AI 生成素材必须记录工具、日期、prompt 摘要和人工修改情况。
