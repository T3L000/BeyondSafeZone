# 《保护区之外》策划概要案

更新日期：2026-06-03

## 1. 设计目的

本概要案用于制作前期统一系统方向。它描述基础规则、大致流程、异常处理和创新点，不替代详细数值表。

当前近期 Demo 只证明一个核心命题：

> AI 可以不是聊天框，而是隐藏主角。它根据人格和可感知信息行动，并真实改写玩家所在的世界。

一周目不能只把 AI 当作结尾反转。玩家需要在过程中通过异常调查读懂“有第二行动者”，并通过世界内标记给祁眠 AI 提供可感知输入。

## 2. 基础规则

### 2.1 时间规则

- Demo 保留 15 天叙事框架，但近期可玩内容是 10-15 分钟最小纵切。
- 每天分为清晨、白天、黄昏、夜晚、结算。
- Day 7 和 Day 15 是血月。
- Day 11-14 是红潮夜设定，近期可先作为文本压力或后续扩展。

### 2.2 林行规则

- 林行是普通幸存者。
- 白天只能选择有限地点探索。
- 夜晚只能执行有限据点行动。
- 状态过差会影响探索收益和结局。
- 最终撤离需要保护区线索、地址线索和旧车修理完成。

### 2.3 祁眠规则

- 祁眠 Day 1-4 昏睡，Day 5 醒来。
- 一周目祁眠由 AI 控制，不直接给玩家操作。
- 普通丧尸不会主动攻击祁眠。
- 祁眠主要风险是人类目击、筛查、探照灯和组织追踪。
- 祁眠不能读取林行后台数据，只能从痕迹、广播、尸群、区域热度等可感知信息判断。

## 3. 大致流程

```text
Day Start
  清晨事件、消耗、状态变化、广播线索

Daytime
  玩家在节点地图选择地点
  进入房间搜索
  获得资源 / 线索 / 风险

Dusk
  返回据点
  记录白天探索结果

Night
  玩家选择一个据点行动
  夜晚压力结算
  祁眠 AI 结算

Next Morning
  地图显示祁眠造成的异常痕迹
  异常档案更新，玩家验证自己的推断
```

## 5. 异常问题处理

| 问题 | 处理规则 |
|------|----------|
| 玩家资源不足 | 不立即失败，转化为状态压力和低收益 |
| 玩家未修好车 | Day 15 进入较差结局或失败线 |
| 感染风险过高 | 夜晚扣生命、加压力，但不随机即死 |
| 探索超时 | 强制进入黄昏/夜晚，并增加疲劳 |
| 房间有隐藏丧尸 | 谨慎搜索降低风险，快速搜索提高伤病/感染惩罚 |
| 祁眠拿走资源 | 必须留下可读痕迹，不能让玩家觉得系统无故扣资源 |
| AI 影响关键通关资源 | 保证不切断最小通关路线，可通过其他地点或匿名补给回流 |
| 玩家看不懂 AI | 异常必须写入“未知行动者档案”，并给出可验证推断 |
| 玩家无法影响 AI | 允许玩家留下有限标记，作为祁眠夜晚 AI 的可感知输入 |
| 第二周目体量过大 | 近期不做；关键行动章节列为后续扩展 |

## 6. 创新与改进点

### 6.1 AI 行为可解释

祁眠 AI 的每次行动都能在通关后回放。日志不是普通日记，而是结构化说明：

- 输入状态
- 可选任务
- 人格排序
- 最终行动
- 地图改写
- 主观残句

### 6.2 一周目 AI 可读、可推断、可影响

一周目增加“异常调查 + 隔空标记”玩法。玩家发现祁眠留下的痕迹后，系统将其写入未知行动者档案；玩家可在离开地点前留下世界内标记，例如危险标记、求助标记、路线提示或保留物资。祁眠 AI 夜晚只把这些标记当作可感知输入，不直接读取玩家后台状态。

核心体验从：

```text
我遇到异常 → 结尾告诉我是 AI
```

改为：

```text
我遇到异常 → 我记录它 → 我推断规则 → 我留下输入 → AI 夜里响应 → 我第二天验证推断
```

### 6.3 AI 不是全知系统

祁眠不能直接读取玩家后台数据。系统可以结算后果，但祁眠的决策必须来自他可感知的信息。

### 6.4 一周目和二周目的信息差

第一周目玩家看见结果、记录异常、尝试留下标记；通关日志让玩家理解原因。第二周目祁眠视角是后续扩展，不进入近期最小 Demo。
