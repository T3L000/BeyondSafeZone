## 1. 系统概述

游戏采用“一周目林行求生 + 隐藏祁眠 AI 行动 + 通关日志揭示”的结构。

第一周目中，玩家只控制林行。祁眠在第 5 天醒来后由 AI 夜间行动。林行和祁眠共享同一套地点状态，但分时段结算：林行白天改写地图，祁眠夜晚继续改写地图，次日林行看到结果。

第一周目不能只让玩家被动接受“看似随机”的 AI 后果。第 5 天之后，玩家会通过“异常调查 + 隔空标记”逐步读懂未知行动者的行为模式，并用世界内痕迹间接影响祁眠 AI。玩家仍不知道对方是祁眠，但可以验证：自己留下的标记会改变夜晚之后的地图结果。

## 2. 核心循环

```text
清晨
  状态消耗、广播、事件、独白

白天
  节点地图选点
  进入地点
  房间搜索
  获得资源/线索/伤病/感染风险
  发现异常痕迹并更新未知行动者档案

黄昏
  返回据点
  汇总探索结果
  可在当前地点留下标记/保留物资

夜晚
  据点行动
  血月/红潮/普通夜结算
  祁眠 AI 读取可感知痕迹并行动

次日
  共享地图状态更新
  玩家发现异常痕迹
  玩家验证自己的推断
```

## 3. 功能规则

### 3.1 日夜循环

| 阶段 | 玩家行为 | 系统行为 |
|------|----------|----------|
| 清晨 | 阅读状态和事件 | 扣资源、应用天数事件、提示线索 |
| 白天 | 选择地点并探索 | 处理路程、疲劳、房间搜索、拾取 |
| 黄昏 | 返回据点 | 锁定当天探索结果 |
| 夜晚 | 选择据点行动 | 处理设施、血月/红潮压力、祁眠 AI |
| 揭示 | 阅读日志 | 展示隐藏因果链 |

### 3.2 状态系统

| 状态 | 功能 |
|------|------|
| 生命 | 降至过低会影响结局或崩溃 |
| 饥饿 | 食物不足时上升，影响状态 |
| 口渴 | 水不足时上升，影响状态 |
| 疲劳 | 探索、路况、超时增加；睡床降低 |
| 压力 | 血月、伤病、坏消息增加；希望和事件可缓解 |
| 感染风险 | 受伤和隐藏丧尸增加，药品可降低 |
| 希望 | 保护区线索、修车进度和关键事件影响 |

### 3.3 资源系统

| 资源 | 用途 |
|------|------|
| 食物 | 每日生存消耗 |
| 水 | 每日生存消耗 |
| 药品 | 治疗伤口、降低感染风险 |
| 建材 | 封窗、修车、设施维护 |
| 零件 | 自行车维护、汽车修理、工具 |
| 燃料 | 调试引擎或发电/载具相关消耗 |
| 电瓶 | 汽车修理关键件 |
| 汽油 | 汽车加油关键件 |
| 轮胎 | 汽车修理关键件 |

### 3.4 节点地图

完整版地图由 14 个地点组成，但近期最小 Demo 只做 4 个核心地点：

| 地点 | 功能 |
|------|------|
| 林行家/据点 | 夜晚经营、资源消耗、修理旧车或撤离准备 |
| 社区诊所 | 药柜异常、求助标记、匿名药品，是 AI 链路核心 |
| 小区超市 | 基础搜刮和资源变化，展示地点被二次改写 |
| 自行车修理铺+车库 | 旧车/零件/撤离目标的最小表现 |

14 地点结构作为后续扩展和参考资料保留：

| 圈层 | 地点 |
|------|------|
| 近圈 | 林行家、小区便利店、社区诊所、自行车修理铺+车库 |
| 中圈 | 超市、废弃学校、派出所、地铁口、桥洞营地、加油站、五金店、废弃公寓 |
| 远圈 | 城市边缘哨卡、防疫隔离站 |

地点卡显示：

- 地点名
- 圈层
- 路程
- 路况
- 危险等级
- 资源倾向
- 图标标签
- 是否被搜索
- 是否存在祁眠异常痕迹

### 3.5 室内搜索

每个核心地点近期只要求 1-3 个房间或节点。完整房间数据作为后续扩展保留。

房间字段包括：

- 房间名
- 能见度
- 搜索耗时
- 隐藏丧尸数量
- 可获得资源
- 剧情旗标
- 是否上锁
- 是否已搜索

玩家可执行：

- 谨慎搜索：风险低，耗时正常。
- 快速搜索：速度快，但隐藏丧尸和感染风险更高。
- 制造声音引开：增加局部噪音，降低该房间隐藏丧尸直接伤害。
- 离开地点：进入黄昏。

### 3.6 据点设施

| 设施 | 功能 |
|------|------|
| 床 | 降低疲劳和压力 |
| 工作台 | 修车、处理零件、制作简单工具 |
| 封窗 | 提升血月防守和据点安全 |
| 收音机 | 获取保护区、血月、返生计划线索 |
| 储物/整理台 | 提升物资保存和撤离携带效率 |

### 3.7 汽车撤离系统

汽车是最终撤离条件，自行车只负责近中圈探索。

最小 Demo 中，汽车流程可以简化为“发现旧车 → 找到关键零件 → 最终出发”。完整修理流程保留为参考：

| 步骤 | 条件 | 结果 |
|------|------|------|
| 发现旧车 | 搜索修理铺车库，触发 `car_found` | 解锁汽车修理 |
| 接引擎线路 | 建材 x2 + 零件 x1 | `step_engine = true` |
| 换轮胎 | 轮胎 x1 + 零件 x1 | `step_tire = true` |
| 装电瓶调试 | 电瓶 x1 + 燃料 x1 | `step_battery = true` |
| 加油 | 汽油 x2 | `car_ready = true` |

Day 15 出发后旧车必然故障，进入徒步撤离叙事段。

### 3.8 夜晚压力

- Day 7：教学型血月或压力提示，验证基础夜晚结算。
- Day 11-14：红潮夜，近期可作为背景压力和文本提示，不要求完整逐夜演出。
- Day 15：终局血月，林行已经离开据点，压力集中在撤离叙事和结局判断。

### 3.9 祁眠 AI

AI 状态：

- 醒来状态
- 暴露值
- 摩托等级
- 区域热度 A/B/C
- 祁烬线索进度
- AI 背包库存

AI 流程：

```text
感知世界
→ 收集可用任务
→ 按人格规则排序
→ 执行任务
→ 更新共享地图
→ 更新暴露/热度/线索
→ 写入日志
```

候选任务包括：

- 巡逻
- 搜刮
- 匿名补给
- 追踪祁烬
- 清桥
- 引偏尸群
- 留药
- 休整

### 3.10 异常调查系统

异常调查是一周目让玩家“玩懂 AI”的核心入口。系统不直接告诉玩家“祁眠做了什么”，而是把地点变化转成可观察痕迹，写入“未知行动者档案”。

异常来源：

| 异常标签 | 触发示例 | 玩家推断 |
|----------|----------|----------|
| 新鲜撬锁痕 | `lock_state` 从 locked 变为 picked | 有人夜里来过，而且尽量不破坏现场 |
| 便携食物减少 | 易携带食物减少但重物未动 | 对方只拿任务所需资源 |
| 摩托胎痕 | 地点或路线出现夜间胎痕 | 对方有快速载具 |
| 尸群被引偏 | 丧尸密度下降或路线恢复 | 对方能影响尸群路线 |
| 匿名药品 | 据点或地点出现药品包 | 对方不完全敌对 |
| 荧光标记 | 墙面/门框出现符号 | 对方使用自己的标记语言 |

未知行动者档案字段：

- 已发现异常列表。
- 异常出现地点和日期。
- 玩家可见证据文本。
- 当前推断标签，例如“谨慎”“会救人”“有摩托”“避开筛查”。
- 已验证/未验证状态。

设计要求：

- 档案只记录林行能看见的证据，不提前揭示祁眠身份。
- 每个异常至少能对应一个共享地图字段变化，便于代码和测试验证。
- 中段必须形成 2-3 条可复现链路，让玩家知道异常不是随机装饰。

### 3.11 隔空标记系统

隔空标记让玩家在一周目间接影响祁眠 AI。林行离开地点前，可以留下少量世界内痕迹；祁眠夜晚只把这些痕迹作为可感知输入，不读取林行血量、背包或玩家计划。

可留标记：

| 标记 | 玩家意图 | 祁眠 AI 可能响应 |
|------|----------|------------------|
| 危险标记 | 提醒该处有尸群/巡逻/陷阱 | 避开区域，或优先清路线 |
| 求助标记 | 表示附近有人需要药/水/转移 | 提高救援、匿名补给、留药权重 |
| 路线提示 | 暗示某条路线可通或需要清理 | 提高巡逻、清桥、引偏尸群权重 |
| 物资保留 | 玩家故意不拿某类物资 | 祁眠可判断“这里留给别人”或取用任务所需 |

最小可玩链路：

```text
Day 6 林行进入诊所
→ 发现药柜被重新锁过，档案记录“夜间来访者”
→ 离开前留下求助标记：这里还有发烧的人
→ Day 6 夜里祁眠 AI 感知标记、药品剩余、低暴露风险
→ 人格规则“会帮助近处的人”压过普通搜刮
→ Day 7 清晨，林行看到匿名抗生素和一条浅箭头
→ 档案更新：对方能理解幸存者标记，且不完全敌对
```

## 4. UI/UX 说明

当前灰盒 UI 以清晰表达系统状态为优先。

主要界面：

| 界面 | 内容 |
|------|------|
| 顶部状态栏 | 天数、阶段、目标、血月/红潮提示 |
| 状态面板 | 林行生命、疲劳、压力、感染风险、希望 |
| 资源面板 | 六类基础资源和汽车零件 |
| 节点地图 | 地点卡、风险、资源倾向、路况、异常标记 |
| 房间搜索 | 房间卡、能见度、耗时、风险、搜索按钮 |
| 未知行动者档案 | 异常列表、证据、推断标签、验证状态 |
| 标记选择 | 危险、求助、路线、物资保留四类标记 |
| 据点面板 | 五大设施和夜晚行动 |
| 揭示界面 | 祁眠人格卡、逐日 AI 日志、主观残句 |

UI 原则：

- 不隐藏关键状态。
- 异常痕迹要可见但不直接揭示身份。
- 玩家留下的标记要有次日可验证反馈，哪怕反馈很轻。
- 按钮文案必须说明成本或不可用原因。
- 终局日志要能展示“决策链”，不是只展示剧情文本。

## 5. 剧情需求

核心角色：

| 角色 | 定位 |
|------|------|
| 林行 | 普通幸存者，一周目玩家角色 |
| 祁眠 | 感染后未变成丧尸的夜行者，一周目隐藏 AI 主角 |
| 祁烬 | 祁眠哥哥，返生计划相关人物，Demo 中不直接出场 |

剧情结构：

1. 林行醒来，确认城市沦陷。
2. 林行通过探索和广播确认保护区仍可能存在。
3. 祁眠 Day 5 醒来，开始寻找祁烬。
4. 玩家通过异常档案发现地图异常正在形成模式。
5. 玩家尝试用危险、求助、路线或物资标记隔空影响未知行动者。
6. 红潮夜逼近，林行必须修车撤离。
7. Day 15 林行抵达保护区外，祁眠藏身尸群并间接改变路线。
8. 通关后解锁祁眠日志，揭示隐藏因果。

## 6. 美术需求

美术方向为 2D 像素。

优先素材：

- 林行动作：待机、行走、搜索、受伤、骑车。
- 祁眠动作：待机、行走、搜索、救援、隐藏、骑摩托相关。
- 普通丧尸和血月丧尸。
- 核心地点：林行家、便利店、诊所、修理铺、超市、学校、派出所、地铁口。
- UI 图标：食物、水、药、建材、零件、燃料、危险、血月、祁眠痕迹、异常档案、隔空标记。

当前可使用占位素材，但比赛提交前需统一风格并确认版权。

## 7. 音乐音效需求

音频方向偏克制末日氛围。

优先音效：

- 风声、雨声、远处尸潮、血月低频噪音。
- 按钮点击、拾取、开门、锁门、搜索。
- 自行车链条、摩托启动、引擎声。
- 收音机静电、广播切入。
- 受伤、丧尸低吼、封窗敲击。

音乐只在关键回放和结尾处使用，避免常驻背景音乐削弱压力。
