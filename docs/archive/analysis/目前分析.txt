二、世界观设定
2.1 灾难起源
20年前，三名男孩（林行、祁眠、祁烬）沉迷丧尸游戏并一起绘制了幼稚但认真的"末日避难计划"。20年后，名为 "返生计划"(Rebirth Project) 的组织完成感染源扩散。该组织外表为科研项目（感染研究、延寿、净化），内部已宗教化——视感染为"返生"，城市失控为"筛选"，幸存者痛苦为"必要代价"。

2.2 城市三层结构
外围生活区：林行初期活动范围，资源少、信息闭塞
沦陷城区：丧尸密集，普通人难以进入，祁眠可夜间穿越
保护区：人类临时政权+军方残部控制区，林行暂时无法抵达
2.3 丧尸规则
普通丧尸白天迟缓、夜晚活跃
声音、血味、强光变化吸引丧尸
感染者间有微弱识别机制 → 祁眠不被普通丧尸主动攻击
特殊丧尸仍可攻击祁眠
2.4 血月/红潮夜系统
时间	事件	性质
第7天	第一次血月	教学型防守压力，失败只损据点不直接终结
第11-14天	红潮夜逐步加密	频率递增的高压夜晚（非血月，由返生计划扩散/火光粉尘/广播干扰/尸群躁动造成）
第15天	第二次血月（终局）	逃亡型：林行白天撤离据点，夜晚血月降临，与含祁眠的尸群擦肩
三、角色设计
3.1 三名核心角色（均为男性）
林行（Lin Xing）— 普通幸存者 / 玩家第一视角
维度	设定
原型	原C
定位	普通幸存者，童年和双胞胎兄弟一起玩丧尸游戏
关系	与祁眠是童年亲密、成年断联的旧友；三人幼年共同绘制过"末日避难计划"
开局	从自己家中醒来，发现世界已变
交通	自行车
玩法周期	白天探索搜集 → 黄昏整理分配 → 夜晚经营据点
核心矛盾	不知道祁眠还活着，不知道世界变化来自祁眠，以为面对随机末日
祁眠（Qimian）— 夜行无症状感染者 / AI控制隐藏主角
维度	设定
原型	原B
定位	双胞胎弟弟，感染后昏睡数日醒来成为无症状感染者
时间线	第1-4天昏睡，第5天醒来确认自身变化，迷茫后定下"寻找哥哥祁烬"为主任务
特性	普通丧尸不攻击；对光线敏感但非畏惧阳光；夜行主要是为了避开林行、人类巡逻和保护区检测
交通	摩托车
日间藏身点	郊区山上别墅小屋（不回原本家，因现实暴露风险+情感上不敢带回"改变后的自己"）
玩法周期	白天藏匿休整/整理线索 → 夜晚执行任务（侦查、引尸、转移幸存者、偷拿物资、追查祁烬）
核心矛盾	想找哥哥也想救人，但不能轻易进入保护区；能穿越尸群却更难被人类信任
祁烬（Qijin）— 灾难助推者 / AI控制倒计时角色
维度	设定
原型	原A
定位	双胞胎哥哥，加入/参与创立"返生计划"，儿时最迷恋丧尸题材
关键矛盾	参与了灾难，也最想结束灾难；不能公开忏悔（组织仍控制资源、实验体和净化装置）
终局机制	"白昼协议"——组织留有城市级净化装置，启动后烧毁感染源和大部分丧尸，代价是保护区外所有人（含无为症状者、实验体）几乎都会死亡
Demo定位	不作为完整可操作主角，而是AI控制的倒计时事件/终局选择
四、核心玩法机制
4.1 林行线：日行求生（玩家可控）
每日四阶段循环：

清晨结算 → 白天探索 → 黄昏分配 → 夜晚经营
(饥饿/伤病/血月预警) (骑自行车选地点潜行) (整理背包/修车) (加固据点/治疗/无线电)
核心数值（8项状态）：

生命、饥饿、口渴、疲劳、伤病、精神压力、感染风险、希望值
据点状态（8项）：

门窗耐久、噪音等级、气味等级、光源等级、储物空间、卫生等级、逃生通道、防御等级
自行车状态（6项）：

耐久、轮胎、链条、载重、速度、噪音
核心资源（6类）： 食物 | 水 | 药品 | 建材 | 自行车零件 | 燃料

据点设施（5个核心）：

设施	功能
床铺	降低疲劳/压力，影响次日探索效率
工作台	修车、制作简易工具、处理门窗材料
封窗	影响血月防守与逃亡前损失
收音机	获取保护区线索、血月预警、返生计划异常广播
储物/整理台	提升保存效率，影响终局可携带物资
探索系统：

大地图：节点式像素地图，地点节点+路线连接+资源倾向+危险等级+状态图标
室内搜索：俯拍小型潜行关卡（参考《迈阿密热线》房间布局），目标为"拿够就走"
视觉规则：无光房间无视野；有窗且无雨时提供部分视野；下雨削弱窗户视野
丧尸应对：躲避 > 绕路 > 关门 > 制造声音引开 >> 有限反击（近战为主，枪械极稀缺+高风险）
惩罚：受伤/感染风险 + 时间/疲劳（探索太久天黑）
撤离三条件：

确认保护区仍在（通过收音机）
知道具体地址（通过地图/哨卡/路标）
拥有足够载具状态（自行车修理铺+零件）
4.2 祁眠线：夜行救援（AI控制 / 二周目解锁可玩）
核心玩法定位：任务驱动型夜行潜行，非据点经营

维度	设计
白天	藏匿、休整、整理线索、判断今晚任务、避免被目击
夜晚	前往目标地点，侦查/潜入/引尸/转移幸存者/偷拿关键物资/追查祁烬
核心压力	暴露风险（不能公开证明丧尸不攻击他）、异常痕迹（不能留下超常行动证据）、藏身压力（白天需安全隐匿点）、体征波动、保护区怀疑
铁律	可以靠近/穿越尸群，但不能在人类目击下证明自己不怕丧尸
4.3 共享世界（核心创新）
执行原理：同一套地点节点 + 同一套地点状态 + 分时段顺序结算

林行白天探索 → 改写地点状态
祁眠夜晚行动 → 读取并继续改写状态
次日林行看到后果
共享状态（6类）： 剩余资源 | 门锁/入口状态 | 尸群密度 | 路线是否通行 | 是否有幸存者 | 是否有异常痕迹

关键展示案例（4类）：

超市二次进入——物资被别人动过
诊所药柜被精准拿走
桥梁/路口尸群被改道
匿名留下药品或工具
4.4 AI系统设计
核心原则：AI不是聊天装饰，而是隐藏主角的行为引擎

人格卡系统：

卡面维度	内容
核心性格	谨慎/偏执/利他/冷漠/强迫收集/风险偏好
能力	夜间行动、开锁、医疗、路线记忆、谈判、潜入
缺点	昼夜错位、容易心软、极端节省、一点不留、讨厌保护区、过度冒险、害怕暴露身份
道德底线	是否偷拿幸存者物资、是否救陌生人、是否牺牲少数换多数
Demo默认人格卡（固定一张，保证叙事和测试稳定）：

主目标：寻找哥哥祁烬
行为倾向：谨慎，避免暴露
道德规则：会救近处的人，但不主动承担大规模救援
资源习惯：只拿自己任务需要的东西
保护区态度：想靠近观察，但不信任筛查体系
AI决策流程（确定性，非概率）：

祁眠可感知状态 → 生成可行行动列表 → 按人格规则过滤排序 → 选出最优行动 → 执行/改写世界状态
AI约束：

只读取祁眠自己能看见/听见/推断的信息
不能读取林行等幸存者后台状态
不能知道某地是否被林行探索过
允许有限推断（如新鲜自行车胎印、熟悉撬锁痕迹），但不能直接知道对方身份
一周目AI感知节奏：

第5-6天：出现第一次异常（资源被精准拿走、门锁被安静撬开）
第7-10天：异常痕迹形成稳定模式，玩家开始怀疑有第二行动者
第11-14天：玩家知道"有人在地图里行动"，但不知道是谁
通关后：解锁祁眠完整行动日志
五、关卡/地点规划
5.1 三圈地点结构（Demo 12个地点）
圈层	地点	访问条件

声音系统设计	🟡 中	策划案多处提到"噪音"作为核心机制（吸引丧尸、暴露风险），但缺乏声音传播范围、衰减规则、不同行动噪音量级的具体数值定义
UI/UX信息架构	🟡 中	虽有UI图标清单，但完整面板布局（据点界面、探索界面、日志回放界面）的原型设计未文档化
祁眠人格卡扩展规则	🟢 低	长期目标是每局随机生成人格卡，目前Demo用固定默认卡。随机生成的约束边界和扩展方案未规划

10.2 核心系统模块与技术需求
模块A：时间与日夜循环系统
需求编号: SYS-001
功能: 管理15天每日四阶段（清晨/白天/黄昏/夜晚）的状态推进
输入: 当前天数(1-15)、阶段枚举
输出: 阶段性事件触发、血月/红潮夜标记、每日结算数据
技术要点:
  - 确定性状态机（不使用随机数）
  - 天数不可逆递增
  - 清晨结算需合并所有前夜影响（饥饿/口渴/伤病/疲劳/精神/据点损坏/天气）
  - 血月夜: day 7 + day 15
  - 红潮夜: day 11-14（不含day 15）
已完成度: 已实现灰盒核心
模块B：林行生存状态系统
需求编号: SYS-002
功能: 管理林行8项核心状态数值
状态列表: 生命、饥饿、口渴、疲劳、伤病、精神压力、感染风险、希望值
技术要点:
  - 饥饿/口渴每日固定消耗，探索和受伤额外消耗
  - 疲劳影响次日探索效率和有效时间
  - 感染风险分阶段: >=3 发热风险, >=5 危险感染(夜间健康/压力惩罚)
  - 希望值为软性指标，影响某些事件可用性
  - 伤口和感染分开处理: 伤口可恢复，感染只能压制/延缓/降阶段
已完成度: 已实现核心状态+感染阶段系统
模块C：据点管理系统
需求编号: SYS-003
功能: 管理5个核心设施和8项据点状态
设施:
  - 床铺: 恢复疲劳/压力 → 影响次日探索效率
  - 工作台: 修自行车/制作简易工具/处理门窗材料
  - 封窗: 影响血月防守效果和逃亡前物资损失
  - 收音机: 触发保护区确认/地址线索/血月预警/返生计划异常广播
  - 储物/整理台: 提升保存效率，影响终局可携带物资量
据点状态: 门窗耐久、噪音等级、气味等级、光源等级、储物空间、卫生等级、逃生通道、防御等级
技术要点:
  - 血月夜: 噪音+气味+光源决定袭击强度，门窗耐久+陷阱+逃生通道决定防守结果
  - 燃料可用于发电机（照明/收音机）但显著增加噪音风险
已完成度: 已实现设施+灰盒UI
模块D：资源与背包系统
需求编号: SYS-004
功能: 管理6类核心资源的获取、消耗和存储
资源: 食物、水、药品、建材、自行车零件、燃料
技术要点:
  - 每类资源为整数堆叠
  - 背包有容量上限（受自行车载重和储物设施影响）
  - 探索中获取资源需在背包限制内做取舍
  - 情报/线索不作为堆叠资源，作为布尔旗标(key flags: safezone_confirmed, address_known, bike_ready)
已完成度: 已实现（fuel替代batteries，旗标替代intel）
模块E：大地图与探索系统
需求编号: SYS-005
功能: 节点式大地图选择目的地 + 室内俯拍潜行搜索
大地图子系统:
  - 12个地点节点，按近/中/远三圈分类
  - 每个节点含: resource_tendency, danger_level, route_time, road_condition, icons
  - 路线受天气和尸群迁移影响（耗时、疲劳惩罚）
  - 祁眠痕迹用小图标/qimian_trace标记
室内搜索子系统:
  - 进入地点→searching阶段，含active location/time limit/local noise
  - 每个房间: visibility, search_time, hidden_zombie_count, deterministic resources, searched状态
  - 搜索策略: 谨慎搜索(careful) vs 快速搜索(quick)
  - 隐藏丧尸: 暗室/仓促进屋受伤+感染风险；先lure可避免伤害但消耗时间+增加噪音
  - 超时→疲劳惩罚
  - 目标: "拿够就走"，非必须清空
已完成度: 已实现节点地图+室内搜索灰盒
模块F：AI祁眠决策系统
需求编号: SYS-006
功能: AI控制祁眠的每日行动决策与共享世界影响
核心组件:
  1. 人格卡: 编译为确定性决策规则（非概率权重）
     - 默认卡: 找哥哥优先+谨慎避免暴露+救近处的人+只拿任务需要的+不信任筛查
  2. 可感知状态: 祁眠能看见/听见/推断的信息（非全知）
  3. 可行行动列表: 基于可感知状态生成
  4. 规则排序/过滤: 人格规则驱动的选择
  5. 行动执行: 改写共享地点状态
  6. 行动日志: "AI行动回放 + 祁眠主观残句"结构
技术约束:
  - 祁眠AI不能读取林行等幸存者的后台状态
  - 不能读取某地是否被林行探索过
  - 允许有限推断（痕迹识别），不能直接知道他人身份
  - 同人格卡+同世界状态→同决策（确定性）
已完成度: 已实现Qimian hidden action plan + log reveal，人格卡为固定默认卡
模块G：共享世界状态系统
需求编号: SYS-007
功能: 同一套地点节点+状态，林行白天改写→祁眠夜晚读取并改写→林行次日看到后果
共享状态: 剩余资源、门锁/入口状态、尸群密度、路线阻塞、幸存者存活、异常痕迹
执行规则:
  - 分时段顺序结算（非实时双角色大地图）
  - 同地点二次进入为核心展示手段
  - 祁眠主要通过地点状态变化影响林行
  - 4类标志性案例: 超市二次进入、诊所药柜被拿走、桥梁尸群改道、匿名留下物资
已完成度: 已实现shared-map changes机制
模块H：血月/红潮夜系统
需求编号: SYS-008
功能: 管理两次血月+多次红潮夜的压力结算
事件日历:
  - 第1-6天: 正常夜晚
  - 第7天: 第一次血月（教学型，失败仅损据点+丢失少量资源）
  - 第11-14天: 红潮夜逐步加密（频率递增）
  - 第15天: 第二次血月（终局逃亡型）
技术要点:
  - 收音机提前1-2天预警
  - 血月夜丧尸感知上升
  - 据点噪音+气味+光源→袭击强度
  - 门窗耐久+陷阱+逃生通道→防守结果
  - 血月后据点损坏/路线封锁/祁眠趁乱行动
  - 应呈现为真实守夜过程，非纯文本结算
已完成度: 已实现day7+day15血月结算
模块I：撤离条件与终局系统
需求编号: SYS-009
功能: 判定林行是否满足保护区撤离条件，计算终局状态
撤离三条件:
  1. safezone_confirmed: 通过收音机确认保护区仍在
  2. address_known: 通过地图/哨卡/路标确认具体地址
  3. bike_ready: 自行车修好（可抵达远圈）
终局状态:
  - reached_gate_quarantine: 满足三条件→抵达大门外→通过初筛→隔离观察
  - barely_reached_gate: 部分满足→勉强抵达但状态更差
  - collapsed: 未满足关键条件→失败
已完成度: 已实现三种终局判定
模块J：二周目/祁眠可玩系统（Optional）
需求编号: SYS-010 (Demo可选)
功能: 通关林行线后解锁祁眠可操作视角，林行交给AI
技术要点:
  - 祁眠玩法: 任务驱动型夜行潜行（非据点经营循环）
  - 核心压力: 暴露风险、藏身压力、体征波动、保护区怀疑
  - 任务类型: 侦查、引尸、转移幸存者、偷拿物资、追查返生计划痕迹
  - 铁律: 不可在人类目击下证明丧尸不攻击他
  - 林行AI: 继承一周目玩家行为倾向
已完成度: Demo尚未实现（列入Optional）

十一、总结性发现与建议
当前策划案的核心优势
AI叙事融合度极高：AI不是外挂功能，而是游戏的核心结构——"另一个主角在同一世界真实行动"的定位，完美契合同步赛事的"AI重塑叙事体验"赛道
设计文档工程化程度好：从世界观→角色→玩法→数值→AI决策流程→代码实现，层层递进，多数子系统已可在Godot中灰盒验证
Demo范围克制：很清楚什么是P0必做（林行线+祁眠隐藏AI+15天周期）、什么是Optional、什么是暂时不做
叙事与机制深度绑定：二周目不是简单的"换个角色再玩一遍"，而是"回看一周目的隐藏因果"，形成信息差叙事
