# Archive

本目录存放旧入口、历史报告、临时原型和媒体文件。

归档文件不是当前开发入口。需要查旧设定、旧分析、历史截图或原型时再打开。当前项目入口优先看：

- `HANDOFF.md`
- `docs/planning_package/README.md`
- `docs/UNITY_MIGRATION_PLAN.md`
- `docs/UNITY_MIGRATION_STATUS.md`
- `docs/开发任务拆解.md`

## 子目录

| 目录 | 内容 |
|------|------|
| `legacy_design/` | 旧策划入口和旧 One Page GDD |
| `analysis/` | 历史分析报告和临时分析文本 |
| `technical/` | 旧技术设计报告 |

| `media/` | 历史媒体、音视频和图片 |
| `superpowers/` | 早期 Superpowers 规格文件归档 |
