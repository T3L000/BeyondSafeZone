# 祁眠事件关卡布局（侧视横版）

> **用途**: 代码线建关卡时参照的精确布局数据。
> **视角**: 侧视横版——多层建筑剖面、上下攀爬、声音/影子判断楼层。
> **坐标系**: x=屏幕右为正, y=层(F)。1 屏 ≈ 16m 游戏空间。

---

## 通用交互规则

| 操作 | 按键/方式 |
|------|----------|
| 横向移动 | ← → / A D |
| 攀爬（梯子/管道/窗台） | ↑ 在攀爬点 |
| 蹲行（降噪、躲视线） | ↓ 按住 |
| 跑步 | Shift + 方向 |
| 互动（开门/撬锁/按钮/拾取/喷漆） | E |
| 骑摩托（仅在摩托旁可上/下） | F |
| 投掷引火物 | Q（祁眠携带 3 个） |
| 近战攻击（无双） | 鼠标左键 |

## 事件 B：诊所救医生（难度 ★☆☆）

**定位**: 二周目教学关。祁眠第一次救人。

```
地图尺寸: 1 屏宽 × 3F 高 + 后巷

楼层结构:
  2F ┌──────────────────────────┐
     │  后屋(医生反锁在内)     │───窗───┐
     │  [door: locked, E撬锁]   │         │
  1F ├──────────┬───────────────┤    外墙爬梯
     │ 候诊室   │   走廊        │    │ (可下到后巷)
     │          │ [丧尸×2 徘徊] │    │
  B1 ├──────────┴───────────────┤    │
     │  地下室(引丧尸目标)      │    │
     └──────────────────────────┘    │
                                     │
  后巷  ┌────────────────────────────┘
       │ 祁眠摩托停在此处
       └──→ 骑摩托载医生去桥洞营地
```

| ID | 位置 (x, F) | 类型 | 参数 |
|----|------------|------|------|
| 铁管(引怪道具) | x=4, 后巷 | 互动 | E 敲击 → 1F 丧尸被引到 B1 方向 |
| 后窗 | x=14, 2F | 攀爬点 | 祁眠出生点——从后窗翻入 2F |
| 后屋门 | x=8, 2F | 锁门 | 需撬锁。成功条件: 在 3 秒内按节奏点 E (3 次) |
| 走廊丧尸 ×2 | x=6,x=9, 1F | 丧尸 | 巡逻路径: 6↔10 来回 (周期 5s) |
| 地下室入口 | x=1, 1F | 楼梯 | 下去敲铁管后丧尸会跟下来 |
| 外墙爬梯 | x=14, 2F→地面 | 攀爬链 | 祁眠+医生撤离路线 |
| 摩托 | x=2, 后巷 | 载具 | 按 F 上车 |

**过关流程**:
1. 翻入后窗(2F) — 看到后屋门锁着(医生在里面)
2. 爬下到 1F — 观察走廊 2 只丧尸的巡逻节奏
3. 穿走廊 → B1 敲铁管(引丧尸下 B1)
4. 跑回 2F → 撬锁(2 只丧尸在 B1, 不在身边)
5. 医生爬出 → 带她沿外墙爬梯下 → 后巷上摩托
6. 骑摩托去桥洞营地(自动过场, 1s)

**失败条件**: 撬锁时被丧尸发现(从 B1 回来太快 < 8s) → 丧尸上楼 → 医生受惊关门 → 任务失败。

  └────────────┘   │ 加油泵×2(可取燃料)   │   │ 祁眠喷漆点   │

|----|------|------|------|

5. 倒计时 30s 开始 — 祁眠冲向主干道入口
6. 穿过主干道(绕过剩余 3 只丧尸, 蹲行通过)
7. 到 x=32 喷 ◯

**失败**: 30s 内未穿过 → 丧尸回流堵塞入口 → 任务失败 → 零件奖励丢失, 主干道堵 3 天。

  4F ┌────────────────────┐

```

| ID | 位置 | 类型 | 参数 |
|----|------|------|------|
| 铁丝网缺口 | x=4, 地面 | 入口 | 祁眠出生在铁丝网外, 翻入 |

| 监控摄像头 | x=8, 2F | 陷阱 | 左右慢扫(周期 8s), 站立被拍到 → 暴露 +3, 任务失败 |
| 干扰器 | x=8, 4F | 目标 | E 砸毁(2 下, 每下 1s), 砸第 1 下后警报响 |

6. 砸干扰器(第 1 下 → 警报! 安保从缺口跑向塔前守门)

**失败**: 被安保或监控发现 → 暴露值 +3, 任务失败, 安保此后加强(热度永久 +1 在 C 区)。

| ID | 位置 | 类型 | 参数 |

3. 第 2 圈(16-30s): 4 只丧尸撞窗, 玻璃裂纹(耐久 1 闪烁红)。专注转轮
4. 第 3 圈(31-45s): 玻璃碎裂! 1 只丧尸冲入。**祁眠双手操作**: 左手按住 E(继续转轮)+右手鼠标点击推开丧尸(丧尸对祁眠犹豫 1s = 操作窗口)
5. 每推开一次丧尸退 2m → 它会再冲过来
6. 第 3 圈完成 → 闸门轰然落下(cutscene: 2s 震动+音效)
7. 上 3F → 消防梯滑下 → 到摩托处

**Lv.3 摩托捷径**: 自动检测 → 祁眠用摩托引擎发电驱动闸门电机 → 2s 完成 → 无丧尸环节。

**失败**: 转轮途中放手(去推丧尸或逃跑) → 闸门只关了 1-2 圈 → 低洼街区被淹推迟 1 天(部分效果, 不完全失败)。

```
